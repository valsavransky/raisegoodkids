# Content Library: Kindergarten–2nd Grade (ages 5–7)
*Companion to screens-and-flows.md. Starting content set for Expected & Gigs setup (screen 7). Meant to be tested and revised with real families before it's treated as final — not a finished, authoritative list. Last updated: Sept 16, 2026.*

The second grade band authored, alongside `content-library-grade-3-4.md`. Covers K through 2nd grade as one band rather than one list per grade — at this age the real variable is how much help a task needs, not which tasks exist at all, so a K-2nd item list stays mostly the same across the band while the amount of adult involvement shrinks as a child moves through it.

**This is not just an easier version of the 3rd/4th list.** A 5-to-7-year-old's realistic independence is a different shape: shorter tasks, more "with help"/supervised framing, and a hard line against anything requiring unsupervised heavy lifting or sharp/hot tools. That's why several items below are phrased "with help" or "with a grown-up" rather than assuming solo completion, and why there's no Big Job tier at all in the Gigs list.

---

## Expected items (unpaid, daily/weekly responsibilities)

No effort tier or dollar value — same rule as every other grade band.

| Item | Frequency | Notes |
|---|---|---|
| Get dressed by yourself | Daily | |
| Brush teeth, morning and night | Daily | Same item as 3rd/4th — a universal habit, not age-scaled. |
| Make your bed (with help) | Daily | Straightening covers/pillow, not hospital corners — a grown-up can still be doing most of the actual bed-making early in this band. |
| Put toys away before bed | Daily | |
| Put dirty clothes in the hamper | Daily | Same item as 3rd/4th. |
| Clear your plate after meals | Daily | |
| Put backpack and shoes by the door | Daily (school days) | The K-2nd equivalent of 3rd/4th's "pack your own backpack" — packing it is still mostly a parent task at this age; putting it away when they get home is the realistic independent piece. |
| Tidy your room with a grown-up | Weekly | Explicitly paired, unlike 3rd/4th's solo "Tidy your room" — room tidying at this age is a shared task, not a delegated one. |
| Help set the table for dinner | Weekly | |
| Put away your own clean laundry (socks and folded shirts) | Weekly | A grown-up still folds; matching socks and putting folded items in drawers is the child's piece. |

## Gigs (optional, paid — goal-progress percentage assigned by effort tier, not a dollar value)

No Big Job tier in this band — everything here is supervised or genuinely light. Bigger, less-supervised jobs (yard work beyond a small pile of leaves, deep cleaning, laundry start-to-finish) wait for the 3rd/4th list.

| Gig | Suggested effort tier | Notes |
|---|---|---|
| Water a houseplant | Quick | |
| Match socks from the laundry | Quick | |
| Wipe down the bathroom sink | Quick | |
| Put away the silverware from the dishwasher (no knives) | Quick | Parent pulls knives out first. |
| Dust low shelves and furniture | Quick | |
| Sort recycling into the bin | Quick | |
| Help pack their lunch box | Quick | |
| Help fold and put away towels | Medium | Towels, not fitted sheets — a forgiving shape to practice folding on. |
| Help unload the dishwasher (plastic and unbreakable items only) | Medium | Parent unloads glass/sharp items first. |
| Help carry in light grocery bags | Medium | Light bags only (bread, paper goods) — not anything heavy. |
| Rake a small pile of leaves | Medium | If applicable (has a yard) — a small pile, not the whole yard. |
| Help wash the car with a sponge (supervised) | Medium | If applicable (has a car) — supervised, exterior only, same as the 3rd/4th version but explicitly supervised here. |
| Sort a load of laundry into lights and darks | Medium | Sorting only — starting the machine is the 3rd/4th "Sort and start a load of laundry" version. |

*Feeding/walking a pet aren't listed here either, for the same reason as every other grade band — added automatically, personalized with the pet's name, only for a household that actually has one.*

## Notes for whoever expands this next
- **11 fewer Gigs than 3rd/4th, and no Big Job tier at all** — intentional, not an oversight. This age band shouldn't see suggestions that assume unsupervised use of anything sharp, hot, heavy, or exterior-unsupervised.
- **"With help" / "with a grown-up" framing** replaces 3rd/4th's grade-only independence split (there is no K-only vs. 2nd-only distinction encoded here, unlike 3rd/4th's "4th grade only" items) — at this age the realistic difference across the band is how much the adult is still doing, which reads more naturally as a phrase on the item than as a separate list per grade.
- Same open item as the 3rd/4th doc: this needs real-family testing before any of it is treated as settled, and effort tiers are always parent-overridable.
