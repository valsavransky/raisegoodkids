# Content Library: 3rd & 4th Grade (ages 8–9)
*Companion to screens-and-flows.md. Starting content set for Expected & Gigs setup (screen 7). Meant to be tested and revised with real families before it's treated as final — not a finished, authoritative list. Last updated: Sept 8, 2026.*

This is the first slice of what should eventually be a full age/grade content library. It covers 3rd and 4th grade only, matching the initial design target (an 8-year-old, with an eye toward how it should flex as she moves into 4th grade). Most items apply to both grades; a few are marked 4th-grade-only where a bit more independence felt developmentally reasonable to expect.

---

## Notes for whoever expands this next
- This set is intentionally modest (11 Expected items, 19 Gigs) rather than exhaustive — better to start small and let real usage with your community-testing families (per the vision doc's plan) surface what's missing than to over-author guesses up front.
- **"(if applicable)" tag introduced:** a few Gigs depend on having a specific household feature (a yard, a car) that not every family has. Rather than dropping them, they're tagged so the app can hide or surface them based on the family's actual situation — worth capturing "has a yard" / "has a car" as simple flags somewhere in the household or setup data model, so these can filter automatically instead of every family seeing irrelevant suggestions.
- The 4th-grade-only items reflect a small, deliberate step up in independence (meal prep, starting a laundry load) rather than harder versions of the same tasks — worth keeping that as the pattern when this expands to other grades, rather than just scaling difficulty.
- Effort tiers here are suggested defaults, always parent-overridable per the Expected & Gigs setup decision — don't treat these as fixed.
- No excusable/always-required split is included, consistent with the v1 scope decision to ship a single all-or-nothing daily excuse (see screens-and-flows.md). If that fast-follow feature gets built, this library would need an always-required flag added per Expected item at that point.
