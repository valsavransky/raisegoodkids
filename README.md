# raisegoodkids
An application that helps kids manage their daily and weekly at home responsibilities, set goals, earn additional money with gigs and understand the value of hard work and being part of a community!!!

## Running the app (no local Node install needed)

This repo is set up for [GitHub Codespaces](https://github.com/features/codespaces):

1. On GitHub, click **Code → Codespaces → Create codespace on `<branch>`**.
2. Wait for the codespace to build — it installs dependencies automatically.
3. In the codespace terminal, run:
   ```
   npx expo start --tunnel
   ```
4. Scan the QR code that appears with the **Expo Go** app on your phone ([iOS](https://apps.apple.com/app/expo-go/id982107779) / [Android](https://play.google.com/store/apps/details?id=host.exp.exponent)).
